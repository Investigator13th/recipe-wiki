# 丝瓜烩蛏子

## 1. 食材配比
### 主料
* 翠绿丝瓜（水瓜）：1根
* 新鲜大老蛏（插蛏）：300g

### 辅料与调料
* 大蒜：3瓣（拍碎）
* 生姜：2片（切丝）
* 小葱：1根（切段）
* 料酒：1茶匙
* 老抽：半茶匙（调色）
* 白胡椒粉：微量
* 盐：适量
* 水淀粉：1汤匙（薄芡）
* 食用油：适量

## 2. 前置准备
1. **老蛏去壳取肉**：老蛏冷水下锅加热，微沸开壳立即关火捞出，剥出肥美蛏肉，撕去黑边，冲洗去细沙沥干；
2. **切配丝瓜**：丝瓜刮去外皮，切成均匀滚刀长条。

## 3. 烹饪步骤
1. **爆香底料**：热锅倒入食用油润锅，下入葱姜蒜末爆出浓香；
2. **煸炒丝瓜**：下入丝瓜条，撒入少许食盐翻炒引出自然水分，大火翻炒半分钟；
3. **合烹焖煮**：下入焯好的蛏子肉，调入微量老抽上色、1 茶匙料酒去腥、少许胡椒粉和适量开水，盖上锅盖中火焖煮 3 分钟让丝瓜软透入味；
4. **勾芡出锅**：揭开锅盖，淋入 1 汤匙水淀粉轻柔推匀勾薄芡，汤汁黏稠裹在丝瓜与蛏肉上即可关火盛出。

## 4. 关键技巧与避坑指南
* **蛏子忌久煮**：焯水只要微开壳即出锅取肉，久煮肉质缩水发韧。

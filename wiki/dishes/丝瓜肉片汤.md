# 丝瓜肉片汤

## 1. 食材配比
### 主料
* 鲜嫩丝瓜：2根（削去绿硬皮，切滚刀块）
* 猪瘦肉（腰条肉或里脊）：150g（切薄片）

### 上浆用料
* 红薯淀粉（地瓜粉）：2大勺（约15g）
* 盐：小半茶匙
* 清水：少许（肉片洗水后保持湿润）

### 汤底与调味
* 生姜：3片
* 小葱：1根（切葱花）
* 盐：1茶匙
* 白胡椒粉：小半茶匙
* 鸡精：少许
* 食用油：1汤匙

## 2. 前置准备
1. **肉片上浆（晶莹滑润秘法）**：瘦肉切薄片，用清水快速冲洗抓沥一下（肉片带水分腌制时才不会干巴），加小半茶匙盐抓匀底味，放入 2 大勺红薯淀粉充分抓揉均匀，使每片肉表面裹上一层薄薄的半透明粉浆；
2. **切配丝瓜**：丝瓜削去外层老皮，切成适口滚刀块备用。

## 3. 烹饪步骤
1. **炒出丝瓜清甜**：锅中热油，先下葱姜片煸香，倒入切好的丝瓜块大火翻炒 1 分钟炒出丝瓜的植物清香与甜味；
2. **烧开底汤**：加入大碗清水，调入 1 茶匙盐和少许鸡精，大火将汤水烧至大滚沸腾；
3. **沸水下肉片（锁浆防脱）**：务必在汤水剧烈沸腾时，将上好红薯淀粉的肉片分散轻柔滑入锅中（开水能瞬间锁住肉片外表的红薯粉层，使其立即凝固定型、不脱浆、汤水不浑）；
4. **迅速断生出锅**：煮约 30~45 秒，肉片舒展呈粉白色、红薯粉变成晶莹透明外衣时即可关火；撒入白胡椒粉去腥提鲜，盛出装碗。

## 4. 关键技巧与避坑指南
* **首选红薯淀粉**：与土豆淀粉相比，红薯淀粉（地瓜粉）耐煮且透明感更强，包裹肉片烫出的光泽如水晶一般，口感比普通生粉更滑更弹；
* **必须沸汤下肉**：水没开就下肉会导致淀粉融化溶进汤中，不仅汤色变米汤般黏糊浑浊，肉片本身也干瘪干柴。
